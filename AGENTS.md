# AGENTS.md — правила работы в репозитории MusicNX

Этот файл обязателен к прочтению любым агентом (человеком или ИИ), который
меняет код MusicNX. Нарушение правил — блокер для коммита.

## 1. Миссия

MusicNX — автономный музыкальный центр для Raspberry Pi 3 без экрана.
Локальная медиатека и плеер работают всегда, без интернета и без Яндекса.
Яндекс Музыка (каталог, стриминг, «Моя волна», загрузки, тексты) — расширение,
а не условие работоспособности. Управление — только через браузер клиента;
сервер — единственный источник истины, все клиенты равноправны.
Источник истины по требованиям — `SPEC.md`; он приоритетнее любых догадок.

## 2. Одна фаза за раз

Работай только над текущей фазой из `PLAN.md`. Не реализуй будущие фазы «заодно»,
не создавай маршруты, таблицы поведения или UI будущих фаз. Если решение блокирует
будущую фазу — оставь границу (интерфейс + mock), а не реализацию.
По завершении фазы обнови `PLAN.md` (чекбоксы, текущая фаза) и дай отчёт.

## 3. Не придумывать методы `yandex_music`

Любой вызов библиотеки MarshalX (`yandex_music`) должен существовать в
установленной версии. Перед использованием:

1. проверить интроспекцией установленного пакета:
   `uv run python -c "import yandex_music, inspect; print(dir(yandex_music.ClientAsync))"`;
2. сверить с docs `ym.marshal.dev` или OpenAPI `ym.marshal.dev/api`.

Версии зависимостей пиновать (точные версии в `backend/pyproject.toml` и
`frontend/package.json`). Расхождение схемы — warning и деградация, не падение.
Пока фаза P3 не начата, пакет не подключён: используется только mock-адаптер.

## 4. Mock-first

Весь внешний IO (Яндекс, mpv, PipeWire/BlueZ, сеть, файловая система импорта)
живёт за интерфейсом с mock-реализацией. Тесты не ходят в сеть, не требуют токена,
не требуют Pi и не запускают mpv. E2E по умолчанию — mock-режим.
Выбор реализации — конфигом (`mode: mock | real`), а не ветвлением в бизнес-логике.

## 5. Качество перед коммитом

- `make lint` (ruff check) и `make test` (pytest) — зелёные.
- Коммиты conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`,
  `refactor:`. Один коммит — одна связная порция.
- Публичные функции и неочевидные решения — с комментариями на английском.
- Не коммитить секреты, `.env`, `var/`, `node_modules`, `.venv`.

## 6. Не блокировать event loop

FastAPI/asyncio: никаких `time.sleep`, блокирующего I/O, синхронных HTTP-клиентов
и `subprocess.run` в обработчиках. Долгие операции — `asyncio.create_task`,
`asyncio.to_thread`, фоновые задачи с отменой при shutdown. Один SQLite-коннект,
записи — через транзакции и lock.

## 7. Схема БД — только миграциями

Никаких `CREATE TABLE` в рантайме и ручных правок БД. Новая миграция —
`backend/app/database/migrations/NNNN_name.sql` + запись `schema_migrations`.
Миграции идемпотентны по версии, применяются по порядку. Схема в
`docs/DATABASE.md` обновляется в том же коммите.

## 8. Секреты

Токены Яндекса, PIN-хэши и cookie-секреты не попадают в логи, WS, frontend
и сообщения об ошибках. Токены хранит только backend (файл 0600 вне web root).
Логи пропускаются через redaction-фильтр. Не логировать query-параметры с токенами.

## 9. Аудио — без транскодирования и без байтов через Python

- Не транскодировать нигде.
- mpv сам открывает URL/файл; Python не проксирует аудиобайты локального вывода.
- `--stream` (P3) отдаёт оригинальный файл с Range, без перекодирования.
- Управление mpv — JSON IPC; не использовать python-mpv/libmpv.

## 10. Node и Docker

Node.js — только dev-машина (сборка Svelte). На Pi — готовый `backend/app/static`;
браузерный движок на плате не запускать. Docker не является способом запуска
и не должен быть обязательным. systemd user service + linger — целевой запуск.

## 11. Отчёт после фазы

В отчёте: что сделано; как проверить руками; что покрыто тестами; что осталось
до следующей фазы; известные ограничения. Отчёт — в ответе и, если фаза крупная,
в `docs/ROADMAP.md`.

## 12. Без фиктивных заглушек

Запрещены функции/маршруты/кнопки, которые выглядят реализованными, но ничего не
делают. Если функциональность не реализована — её нет в API и UI; в документации
она помечена как «не реализовано до фазы X». Mock — это явно названный mock,
а не имитация готовой функции.

## 13. Язык

Код, имена, комментарии, docstrings, commit messages — английский.
Документация для людей и весь UI-текст — русский. SPEC.md — verbatim, не
редактировать без явной команды.
