# Правовая рамка

Документ не является юридической консультацией. Он фиксирует границы проекта
и обязанности владельца устройства. Требования — [SPEC.md](../SPEC.md) §16.

## 1. Статус проекта

MusicNX — **неофициальный** клиент Яндекс Музыки для личного использования.
Проект не связан с ООО «Яндекс», не одобрен и не поддерживается им.
«Яндекс Музыка», «Яндекс Плюс» — товарные знаки правообладателя; использование
в названии/описании — только для указания совместимости, без претензии на
аффилированность.

## 2. Допустимое использование

- Личное использование владельцем устройства при **активной подписке Яндекс
  Плюс** (или иной действующей подписке, дающей доступ к контенту).
- Прослушивание каталога через официальные механизмы доступа, которые
  предоставляет подписка.
- Скачивание треков «для личного офлайн-использования» — только в объёме,
  разрешённом условиями подписки и применимым правом; без распространения.
- Локальная медиатека — только из файлов, права на которые у владельца есть.

## 3. Запрещено

- Распространять скачанные файлы, публиковать их, передавать третьим лицам,
  использовать в публичных местах без соответствующих лицензий.
- Обходить платную подписку, DRM/технические средства защиты, региональные
  ограничения; использовать чужие аккаунты/токены.
- Продавать доступ к устройству/контенту, предоставлять сервис третьим лицам.
- Выставлять MusicNX в интернет как публичный стриминговый сервис.
- Использовать неофициальный API способом, нарушающим условия использования
  Яндекса или применимое законодательство.

## 4. Технические меры в проекте

- Подписка проверяется фактически: без активной подписки доступны только
  30-секундные превью, если API их отдаёт; UI честно показывает статус
  (SPEC §7.2).
- Проект не содержит обхода DRM: encraw расшифровывается библиотекой
  `yandex_music` в рамках штатного доступа подписки, не собственным взломом.
- Нет механизмов шаринга контента, публичных ссылок, multi-user доступа.
- Скачанное хранится локально в каталоге владельца; автоочистка по лимиту
  предусмотрена (P4).
- MusicNX не собирает телеметрию и не отправляет данные третьим лицам, кроме
  запросов к API Яндекса (каталог/стриминг/загрузки/тексты), LRCLIB (только
  artist/title/album/duration для поиска текста) и CDN, необходимых для работы.

## 5. Ответственность владельца

Владелец устройства отвечает за:

- соблюдение условий подписки и лицензий на музыку;
- законность локальной медиатеки;
- сетевую безопасность (не публиковать порт 8080 в интернет до P8 и вообще);
- сохранность токенов (файл 0600, бэкапы без токенов);
- соблюдение авторских прав при любом использовании скачанного.

Разработчик/поставщик кода не несёт ответственности за нарушение владельцем
условий сервисов и законодательства.

## 6. Конфиденциальность

- В репозитории нет токенов, паролей и персональных данных.
- Логи не содержат токенов и подписанных аудио-URL (redaction).
- Данные библиотеки/истории хранятся только локально в SQLite.
- Внешние запросы — только к API Яндекса (P3) и CDN для стриминга/загрузок.

## 7. Лицензии зависимостей

- mpv — GPL; запускается как отдельный процесс, не линкуется с backend.
- Python-зависимости (FastAPI, aiosqlite, pydantic, httpx и др.) — под своими
  лицензиями; см. metadata пакетов.
- yandex_music (MarshalX) — сторонняя библиотека, подключается в P3.
- Svelte/Vite — MIT.
- Код MusicNX — приватный проект; лицензия не выбрана. Перед публикацией
  выбрать лицензию и проверить совместимость.

## 8. Изменения

Правовые риски (изменение ToS, API, региональные ограничения) отслеживаются в
этом документе и в [DECISIONS.md](DECISIONS.md). При существенном изменении
условий сервиса функции, нарушающие их, отключаются, а не маскируются.
